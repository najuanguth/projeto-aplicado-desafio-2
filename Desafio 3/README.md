# Calibração

Execute no terminal desta pasta:

```sh
python 05_main.py
```

É necessário Python 3. Não é preciso instalar pacotes adicionais.

- 03_banco.sql: estrutura do banco, com matrícula e setor do técnico.
- 04_classes.py: classes e operações no SQLite.
- 05_main.py: demonstração com dados fictícios.
- 06_mvp_parte1.md: explicação do código.

Os bancos de demonstração são salvos na pasta dados. Cada execução cria um arquivo novo.
